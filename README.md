# 📊 Analysis of Book Sales — Power BI Dashboard

## Overview
This project showcases a Power BI dashboard designed to analyze book sales and reader engagement.  
The dashboard transforms raw metadata into actionable insights for publishers, product teams, and data enthusiasts.

---

## Key Features
- **Top KPIs**
  - Total Sales: 113M  
  - Average Rating: 3.90  
  - Interested Audience: 86.2K  
  - Total Genres: 581  

- **Visuals**
  - KPI cards for quick metrics  
  - Pie chart: Sales by Product Form  
  - Line chart: Sales by Year (trend analysis)  
  - Table: Genre vs. Sales breakdown  
  - Bar chart: Number of Books by Genre  

- **Design Choices**
  - Canva‑style layout with consistent typography and color palette  
  - Row shading for readability in tables  
  - Fixed category colors across visuals for clarity  
  - Annotations for storytelling (e.g., “Young Adult dominates sales”)  

---

## Insights
- **Young Adult** genre contributes the largest share of sales.  
- Niche genres (e.g., Zombies, Writing) show engagement but limited volume.  
- Paperback remains the dominant product form.  
- Sales spikes observed in early 1900s data trends.
